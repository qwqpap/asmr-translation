## 自动化验证

- `python -m compileall -q asmr_lrc`：通过。
- `python -m asmr_lrc --help`：通过，中文帮助正常输出。
- 初始开发环境 `python -m pytest -q`：31 项通过。
- 覆盖内容包括中文/日文/空格路径、递归扫描、稳定排序、不覆盖、内容指纹、损坏缓存
  隔离、数据结构校验、幻觉/无语音/重复过滤、低置信度耳语保护、真实词级时间切分、
  翻译 ID 和 JSON 校验/重试、LRC 时间戳与原子写入、单文件失败后继续以及退出码。
- 本地 `models/faster-whisper-large-v3/model.bin` 静音冒烟：`large-v3 + cuda + int8_float16`
  成功，3 秒输入耗时 8.83 秒，采样峰值显存约 4093 MiB，ASR 子进程正常退出。
- 真实测试音频首次运行暴露了缺少 `cublas64_12.dll`；安装 CUDA extra 并让子进程注册 pip
  DLL 目录后，已进入重新验证阶段。
- 真实 `tests/voice_test/01-一如往常的长椅上_左右反转.mp3` 端到端完成：ASR 254 条过滤后字幕、
  9B 翻译 64 批、同名 LRC 写入成功；与参考 VTT（266 条）对照时平均时间误差约 0.333 秒，
  粗略字符序列相似度均值 0.461，117/254 条低于 0.45。这个相似度不是语义评分，但已定位
  多处明显 ASR/翻译错误，不能宣称听感验收通过。
- `qwen3.5-0.8b:latest` 在问题片段单批验证时返回了日文假名并被格式校验拒绝；当前推荐保留
  9B 作为协议验证模型，同时把翻译质量作为未完成验收项。

不能用自动化测试冒充已经完成：

- 当前 9B 修改版与官方 Qwen 4B–8B 模型的翻译质量盲评。
- 至少一个 Windows 播放器对最终中文 LRC 的人工兼容性确认。

这些项目必须在真实本地音频与播放器上执行，结果应分别记录漏识别、幻觉、时间偏移、
翻译问题和性能数据。结构测试通过不代表听感验收通过。
